[샘플 문서] 테스트 가이드
※ 연습용으로 만든 가상의 문서입니다. 실제 사내 규정이나 제품 사양과 다릅니다.

1. 테스트 종류
룰 개발 후에는 단위 테스트, 통합 테스트, 성능 테스트 순서로 진행합니다. 단위 테스트는 룰 하나에 대해 입력과 기대 결과를 비교하고, 통합 테스트는 여러 룰이 연결된 흐름 전체를 확인합니다.

2. 테스트 데이터 준비
테스트 데이터는 정상 케이스, 경계값 케이스, 오류 케이스로 나누어 준비합니다. 운영 데이터를 사용할 때는 개인정보를 반드시 마스킹합니다.

3. 테스트 에이전트의 역할
테스트 에이전트는 준비된 입력 데이터로 룰을 대신 호출하여 결과를 자동으로 비교해 주는 도구입니다. 사람이 수작업으로 확인하는 시간을 줄여 주지만, 기대 결과는 사람이 직접 정의해야 합니다.

4. 결함 관리
테스트 중 발견한 결함은 결함 목록에 등록하고, 심각도를 상, 중, 하로 구분합니다. 심각도가 상인 결함은 이행 전에 반드시 수정되어야 합니다.
